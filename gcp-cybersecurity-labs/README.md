# Laboratorios de Ciberseguridad en Google Cloud

Repositorio personal donde documento, con mis propias palabras, los laboratorios prácticos del programa **Google Cloud Cybersecurity**. Cada laboratorio incluye un *write-up* con el contexto, los comandos explicados, la verificación y la perspectiva de seguridad.

> **Aviso:** este repositorio no contiene respuestas de evaluaciones, credenciales temporales ni identificadores de proyectos de los laboratorios. El contenido es una explicación personal de lo aprendido.
